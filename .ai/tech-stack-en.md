# Tech Stack - FlashLearn MVP

## Frontend - Astro with React for Interactive Components
- **Astro 5** - Enables building fast, efficient pages and applications with minimal JavaScript
- **React 19** - Provides interactivity where needed
- **TypeScript 5** - Static typing and better IDE support
- **Tailwind CSS 4** - Convenient application styling
- **shadcn/ui** - Accessible React component library for UI foundation

## Backend - Supabase as Comprehensive Backend Solution
- PostgreSQL database
- Multi-language SDKs serving as Backend-as-a-Service
- Open source solution - self-hostable locally or on custom servers
- Built-in user authentication

## AI Integration - OpenRouter.ai for Model Communication
- Access to wide range of models (OpenAI, Anthropic, Google, and many others)
- Enables finding cost-effective solutions with high efficiency
- API key spending limits for budget control

## Testing - Comprehensive Testing Stack

### Unit & Integration Testing
- **Vitest** - Fast test framework compatible with Vite, native TypeScript support
- **React Testing Library** - React component testing following best practices
- **MSW (Mock Service Worker)** - API request mocking for reliable tests
- **Faker.js** - Realistic test data generation

### End-to-End Testing
- **Playwright** - Cross-browser test automation framework supporting Chrome, Firefox, Safari, and Edge
- **Cypress** - Alternative E2E testing tool with user-friendly interface

### Performance & Accessibility Testing
- **Lighthouse** - Automated audits for performance, accessibility, SEO, and PWA
- **Web Vitals** - Core Web Vitals metrics for real performance monitoring
- **axe DevTools** - Automated accessibility testing per WCAG standards

### Monitoring & Code Quality
- **Sentry** - Production error tracking
- **Vitest Coverage** - Code coverage reports
- **ESLint & Prettier** - Code consistency and formatting

## CI/CD & Hosting
- **GitHub Actions** - CI/CD pipelines with automated test execution
- **DigitalOcean** - Application hosting via Docker containers
- **Supabase Dashboard** - Database and API usage monitoring

## Benefits of This Tech Stack

This technology stack ensures:
- High code quality through unit testing (target: >80% coverage)
- Confidence in core functionality through E2E tests
- Quick regression detection via CI/CD automation
- Production monitoring for rapid issue response
- Consistent code quality across the team
- Accessible and performant user experience
